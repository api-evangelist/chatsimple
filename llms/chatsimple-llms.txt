# Chatsimple (Expertise AI)

> Chatsimple now operates as Expertise AI (expertise.ai). It is an AI agent
> platform for revenue and go-to-market teams: no-code conversational sales
> agents that engage website visitors, qualify and capture leads, book meetings
> and answer from a trained knowledge base ("Expertise Live", the product
> formerly sold as the Chatsimple chatbot), plus a dashboard assistant that
> works a GTM pipeline across ~50 connected tools, a Voice AI assistant and an
> AI-native booking product. API access is sold on the Enterprise tier.

This file is GENERATED by API Evangelist from the public Chatsimple / Expertise
AI surface on 2026-08-13. The provider's own documentation advertises an
llms.txt at https://docs.expertise.ai/llms.txt, but that URL returns HTTP 404,
so this is a substitute, not a copy.

## Developer surface — what actually exists

- Machine-readable API contract: NONE published. No OpenAPI, Swagger, GraphQL
  SDL or AsyncAPI document was found on the API host root, the documentation
  host or the console host.
- Remote MCP server: https://api.expertise.ai/mcp — real and reachable, but
  auth-gated (JSON-RPC -32001 Unauthorized) and entirely undocumented. It
  answers the OAuth discovery routes with {"error":"oauth_not_supported"}.
- REST: four endpoints documented on the Zapier integration page, under the
  base URL https://api.expertise.ai/v0/users. Authenticated with an X-API-KEY
  header plus X-USER-ID and X-CHATBOT-ID.
- Browser embed: a first-party <chat-bot> web component with a documented
  JavaScript API (sendMessage, restart, show, hide). This is the most complete
  public developer surface the company ships.

## APIs

- [Expertise AI Zapier / Leads API](https://docs.expertise.ai/live/integrations/zapier): the only publicly documented HTTP endpoints — connect, webhook subscribe, webhook unsubscribe, get most recent lead. Base URL https://api.expertise.ai/v0/users.
- [Expertise AI MCP server](https://api.expertise.ai/mcp): remote Model Context Protocol endpoint (Streamable HTTP). Auth-gated; tool list not publicly readable.

## Notes for agents

- There is no A2A agent card. /.well-known/agent-card.json and
  /.well-known/agent.json 404 on the real hosts; app.expertise.ai and
  my.expertise.ai answer 200 with an HTML app shell for every /.well-known/*
  path, which is a single-page-app catch-all, not a document.
- No rate limits, error codes or idempotency contract are published.
- The documented REST base URL could not be confirmed live: /v0/users,
  /v0/users/zapier and /v0/users/zapier/get_leads all returned HTTP 404 to an
  anonymous request on 2026-08-13, while /health returned 200.
